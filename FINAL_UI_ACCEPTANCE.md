# Final UI acceptance

The approved reference is the professional dark trading-terminal UI supplied in the conversation.

Acceptance is NOT met by a build-only green check.

Required before releasing APK:
- Dashboard is the first screen.
- Professional dark terminal presentation.
- 6x strategy and LIVE engine indicators.
- Funds/capital/deployed/remaining metrics.
- P&L and win-rate metrics.
- Open positions with entry/LTP/P&L/TSL.
- Today's trades.
- Live market scan/signals.
- Strategy details.
- Funds overview.
- Live activity log.
- Settings for Upstox token, capital and execution mode.
- Bottom navigation for the major sections.
- No old/basic form-style home screen.
- APK builds, installs and launches without app/system ANR.
- Emulator smoke test must capture a clean screenshot of the app, not an Android system error dialog.

Do not call an APK final until all of the above are verified.
